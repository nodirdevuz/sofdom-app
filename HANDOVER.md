## 10. Этап 5: Полноценный Бэкенд на FastAPI + SQLite (Томск, Авито + ЦИАН, Вход по телефону) (21.10.2026)

### Что построено:
1. **База данных (`realty/db.py`):**
   - SQLite в режиме WAL (`PRAGMA journal_mode = WAL`), безопасен для параллельных запросов, схема 1:1 готова к переносу на PostgreSQL (`pg_dump` / migration без переделок).
   - Таблицы:
     * `users`: `id`, `phone` (уникальный), `name`, `token`, `role`, `created_at`, `last_login_at`.
     * `subscriptions`: `user_id`, `plan_code` (`free_trial`, `test_drive`, `sniper`, `family_pro`), `daily_limit` (1, 5, 15, 50), `expires_at`, `status`.
     * `unlocked_contacts`: `user_id`, `apartment_id`, `unlocked_at` (открытый контакт сохраняется навсегда).
     * `favorites`: `user_id`, `apartment_id`, `created_at` (избранные квартиры).
     * `apartments`: 138 реальных квартир Томска от собственников (Авито + ЦИАН), цена, залог, 0% комиссии, комнаты, этаж, фото, координаты, телефон, статус секретной квартиры.
2. **Парсер квартир Томска (`realty/scraper.py`):**
   - **ЦИАН (Регион 4620 = Томск):** сбор квартир с фильтром `is_by_homeowner=1` (без посредников).
   - **Авито (Томск):** парсинг выдачи частников (`user=1`) с авто-решением PoW 439 за 15 мс и выявлением Secret-квартир раннего доступа (`ltrSecretItemModal`).
   - Собирает 114+ объявлений за 4.8 секунды, сохраняет в `realty.db` и обновляет `feed_live.json`.
3. **FastAPI Приложение (`realty/main.py`):**
   - `POST /api/auth/login`: быстрый вход только по номеру телефона (без СМС и звонков-сбросов, 0 ₽ затрат, 0 бюрократии). Выдаёт 1 бесплатный контакт на день.
   - `GET /api/auth/me`: получение профиля, активного тарифа и остатка контактов.
   - `GET /api/apartments`: выдача каталога Томска с фильтрами. Номера телефонов маскируются (`+7 936 •••-••-••`), если пользователь не открыл контакт.
   - `GET /api/apartments/{id}`: карточка квартиры с фотогалереей и описанием.
   - `POST /api/apartments/{id}/unlock`: списание суточного лимита тарифа и открытие настоящего телефона собственника. При исчерпании лимита возвращает 403 `QUOTA_EXCEEDED`.
   - `POST /api/apartments/{id}/favorite`: добавление в избранное.
   - `GET /api/subscriptions/plans`: список тарифов (Тест-Драйв 490 ₽, Снайпер 990 ₽, Семейный Pro 1490 ₽).
   - `POST /api/subscriptions/upgrade`: мгновенный переключатель тарифа для тестов.
   - `POST /api/sync`: запуск обновления квартир в фоне.
   - `GET /api/stats`: статистика агрегатора в реальном времени.
   - Документация Swagger: `http://localhost:8080/docs`.
4. **Интеграция с UI (`realty/index.html` и `realty/realty_aggregator_demo.html`):**
   - Форма входа по номеру телефона в модалке профиля.
   - Автоматическая подгрузка 138 реальных квартир Томска из FastAPI.
   - Кнопка «Показать телефон» открывает контакт через API с проверкой квоты.
   - Переключатель тарифов монетизации прямо в интерфейсе.
5. **Тестирование (`realty/test_backend.py`):**
   - Все 9 сквозных тестов пройдены успешно за 0.035с.
