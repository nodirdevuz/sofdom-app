# SofDom Admin — Панель управления базой недвижимости

Автономное приложение для администратора сервиса **SofDom (Томск)**, пересобранное на архитектуре **KomfortAdmin** с соблюдением строгой чёрно-серой монохромной дизайн-системы **Komfort Go**.

Панель полностью отделена от клиентской витрины поиска квартир и предназначена для оперативного контроля каталога, мониторинга сборщиков, аналитики воронки и управления пользователями.

---

## 🧭 Разделы админ-панели

1. **📊 Пульс базы и метрики (`/overview`):**
   - KPI карточки: Всего квартир (162), Авито ранний доступ 6ч (12), Средняя ставка (27 400 ₽), Раскрытий телефонов (285).
   - Распределение по 4 источникам (Авито Каталог, Авито Ранний доступ, БезПосредников `bsps.ru`, ЦИАН).
   - География по всем районам Томска (Советский, Кировский, Октябрьский, Ленинский, Пригород).
   - Лента последних поступлений с подсветкой источника и времени.

2. **🏠 Каталог объявлений (`/listings`):**
   - Полная интерактивная таблица 162 проверенных квартир Томска с фирменными номерами `SD-1001` .. `SD-1170`.
   - **Фильтры статуса жизненного цикла:** *Все*, *🟢 Активные в поиске*, *🔴 Снято / Сдано*.
   - **Действия в 1 клик:** мгновенное снятие квартиры с поиска (`Снять (сдано)`) или восстановление (`↩ В поиск`).
   - Фильтры по источнику лота, 4 районам Томска и живой поиск по адресу/телефону/ID.
   - Прямой переход к объявлению на сайте через иконку предпросмотра.
   - Синхронизация статусов с клиентской витриной через `localStorage` (`sofdom_rented_offers_v1`).

3. **📈 Аналитика и датчики («Шотчик») (`/analytics`):**
   - **Воронка шагов:** 5-шаговая воронка конверсии от визита до раскрытия телефона собственника (23.0% конверсия).
   - **Сессии и глубина:** Детальный журнал реальных пользовательских сессий с глубиной скролла (25%, 50%, 75%, 100%) и длительностью визита.
   - **Детектор спотыканий (Friction Log):** Мониторинг технических сбоев в реальном времени (битые фото CDN 404, нулевые поисковые выдачи, задержки карт, отказы в геолокации).

4. **👥 Пользователи и модерация (`/users`):**
   - Учет клиентов и тарифов (Free, Pro 24 часа, Безлимит).
   - Модерационные действия: Временный блок (24 часа), Вечный бан, Разблокировка, Удаление насовсем с модальным окном.
   - Регулировка суточных лимитов раскрытия контактов (5, 15, 30 или Безлимит).
   - Автоматическая синхронизация статусов в `localStorage` (`sofdom_admin_users_v2`).

5. **⚡ Сборщики и кэш (`/scrapers`):**
   - Монитор 4 фоновых сборщиков (Авито 6ч поток, Авито Полный каталог Томска, БезПосредников `bsps.ru`, ЦИАН).
   - Прозрачный аудит алгоритма модерации «Реальный хозяин» (проверка частоты телефонов, стоп-слова, маркеры собственника; 162 допущено / 342 отсеяно).
   - Управление Service Worker кэшем и кнопка принудительной инвалидации.

## 🎨 Дизайн-система

- **Цвета:** Монохромный минимализм Komfort Go (`#111418`, `#1F2937`, `#5B6B7A`, `#8A94A0`, `#ECECEC`, `#F7F8F9`, `#FFFFFF`).
- **Иконки:** Векторные SVG Lucide (`strokeWidth={1.8}`). Запрет на цветные эмодзи и кричащие градиенты.

## 🚀 Запуск и сборка

```bash
# Запуск в режиме разработки
cd admin
npm run dev        # Локальный сервер на http://localhost:5173

# Сборка продакшн-версии
npm run build      # tsc -b && vite build -> admin/dist/
```
