# SofDom Admin — Панель управления базой недвижимости

Автономное приложение для администратора сервиса **SofDom (Томск)**, пересобранное на архитектуре **KomfortAdmin**. Полностью отделено от клиентской витрины поиска квартир.

---

## 🧭 Разделы админ-панели

1. **📊 Пульс базы и метрики (`/overview`):**
   - KPI карточки: Всего квартир (162), Авито ранний доступ 6ч (12), Средняя ставка (27 400 ₽), Просмотры телефонов (48).
   - Распределение по 3 источникам (Авито, ЦИАН, БезПосредников) с прогресс-барами.
   - География по всем 4 районам Томска (Советский, Октябрьский, Ленинский, Кировский).

2. **🏠 Каталог объявлений (`/listings`):**
   - Полная таблица 162 квартир Томска.
   - Фильтры по источнику лота, районам города и мгновенный текстовый поиск.
   - Подсветка прямых телефонных номеров собственников и количества фото.

3. **👥 Пользователи и Подписки (`/users`):**
   - Учет клиентов и тарифов (Free, Pro 24 часа, Безлимит).
   - Суточные лимиты открытий прямых контактов и статус активности.

4. **⚡ Сборщики и Кэш (`/scrapers`):**
   - Монитор статуса 3 фоновых сборщиков (Авито 6ч поток, ЦИАН, БезПосредников).
   - Управление PWA Service Worker кэшем и кнопка принудительного сброса.

---

## 🚀 Запуск в разработке

```bash
cd admin
npm run dev
```
Панель откроется на локальном порту (по умолчанию `http://localhost:5173`).

## 📦 Сборка продакшн-версии

```bash
npm run build
```
Готовая сборка размещается в `admin/dist/`.
