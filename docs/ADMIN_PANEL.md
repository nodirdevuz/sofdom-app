# Документация Панели Администратора SofDom Admin

**SofDom Admin** — автономное веб-приложение для управления каталогом, мониторинга сборщиков данных, модерации пользователей и анализа пользовательской активности («Шотчик»).

Приложение построено на базе архитектуры **KomfortAdmin** с соблюдением дизайн-системы **Komfort Go**.

---

## 1. Запуск и сборка

Панель администратора полностью изолирована от клиентской витрины и работает в отдельной директории `SofDom/admin/`:

```bash
# Запуск dev-сервера
cd admin
npm run dev        # Доступно на http://localhost:5173/

# Проверка типов и сборка
npm run build      # tsc -b && vite build -> dist/
```

---

## 2. Дизайн-система Komfort Go (Строгий монохром)

Интерфейс спроектирован по стандартам корпоративной дизайн-системы **Komfort Go**:
- **Цветовая палитра:**
  - `#111418` — основной цвет текста, заголовков и активных кнопок.
  - `#1F2937` — графитовый акцент для второстепенных интерактивных элементов.
  - `#5B6B7A` / `#8A94A0` — нейтральные сланцевые оттенки для меток, подписей и дат.
  - `#ECECEC` / `#F1F2F4` — тонкие деликатные разделители и рамки (1px).
  - `#F7F8F9` — матовый серый фон рабочих экранов.
  - `#FFFFFF` — чистые белые подложки информационных карточек и таблиц.
- **Типографика и элементы:**
  - Строгий запрет на цветные градиенты, радужные бейджи и декоративные эмодзи.
  - Векторные SVG-иконки из библиотеки **Lucide** с фиксированной толщиной штриха `strokeWidth={1.8}`.
  - Табличные числовые значения оформлены моноширинным выравниванием (`tabular-nums`).

## 3. Разделы и функциональность

Боковое меню содержит 5 ключевых рабочих разделов:

### 3.1. 📊 Пульс базы и метрики (`/overview`)
Экран оперативного контроля состояния арендного рынка Томска:
- **4 ключевых KPI:**
  1. *Всего квартир в базе:* **162** активных объекта.
  2. *Авито (ранний доступ 6ч):* **12** эксклюзивных лотов на этапе предварительной индексации.
  3. *Средняя ставка аренды:* **27 400 ₽ / мес**.
  4. *Раскрытий телефонов:* **285** успешных контактов арендаторов с хозяевами.
- **Распределение по источникам:** Индикаторы долей базы с разбивкой (Авито Каталог, Авито Ранний доступ, БезПосредников `bsps.ru`, ЦИАН).
- **География Томска:** Распределение лотов по 4 административным районам (Советский, Кировский, Октябрьский, Ленинский) и Пригороду.
- **Лента свежих поступлений:** Список последних перехваченных квартир с указанием источника, времени добавления и цены.

---

### 3.2. 🏠 Каталог объявлений (`/listings`)
Рабочее место контент-менеджера и оператора базы:
- **Единая таблица 162 квартир** с фотографиями, параметрами комнатности, этажности и площади.
- **Быстрые фильтры:**
  - По источнику: *Все*, *Авито 6ч*, *Авито Каталог*, *БезПосредников*, *ЦИАН*.
  - По району: выбор любого из районов Томска.
- **Живой текстовый поиск:** Мгновенная фильтрация по названию улицы, ориентиру или номеру телефона.
- **Интерактивные действия:** Кнопка быстрого копирования верифицированного номера собственника в один клик.

---

### 3.3. 📈 Аналитика и датчики («Шотчик») (`/analytics`)
Центр контроля конверсий и поведенческой телеметрии:
- **Вкладка 1: Воронка шагов:**
  - Наглядное отображение 5 этапов пути пользователя:
    1. Заход на витрину (1 240 / 100%)
    2. Скролл каталога глубже 25–50% (890 / 71.8%)
    3. Открытие карточки квартиры (540 / 43.5%)
    4. Изучение фотогалереи (390 / 31.5%)
    5. **Раскрытие телефона собственника** (285 / 23.0% — целевое действие).
  - Подсчет величины отвала между соседними шагами.
- **Вкладка 2: Сессии и глубина:**
  - Детализированный журнал реальных визитов: длительность сессии в минутах, процент глубины скролла ленты (25%, 50%, 75%, 100%), количество просмотренных квартир, тип устройства и флаг успешного контакта.
- **Вкладка 3: Детектор спотыканий (Friction Log):**
  - Монитор технических и пользовательских ошибок в реальном времени:
    - *CDN 404 (битые фото)* — ошибки с авто-подстановкой резерва.
    - *0 результатов поиска* — запросы пользователей, где фильтры отсекли все квартиры.
    - *Задержка тайлов карт* — превышение времени ответа серверов Яндекс.Карт.
    - *Отказ в геолокации* — запрет браузера на доступ к GPS.

---

### 3.4. 👥 Пользователи и модерация (`/users`)
Управление учетными записями арендаторов и тарифными планами:
- **Фильтрация по статусам:** Вкладки *«Все»*, *«Активные»*, *«Заблокированные (24ч)»*, *«Бан навсегда»*.
- **Действия над пользователем:**
  - `Заблокировать (24ч)` — временная приостановка возможности открывать телефоны.
  - `Бан навсегда` — бессрочная блокировка профиля.
  - `Активировать` — мгновенное снятие блокировки.
  - `Удалить насовсем` — полное удаление пользователя с подтверждающим модальным окном в стиле Komfort Go.
- **Настройка суточных лимитов:** Модальное окно изменения лимита открытий номеров (5, 15, 30 или Безлимит).
- **Сохранение:** Все изменения немедленно синхронизируются в локальном хранилище браузера (`localStorage: sofdom_admin_users_v2`).

---

### 3.5. ⚡ Сборщики и кэш (`/scrapers`)
Центр управления харвестерами и прозрачный аудит отсева риелторов:
- **Монитор 4 фоновых сборщиков:**
  1. *Авито (Ранний доступ 6ч)* — интервал 30 сек, pre-index перехват.
  2. *Авито (Полный каталог)* — интервал 60 сек, захват всех предложений города.
  3. *БезПосредников (`bsps.ru`)* — интервал 5 мин, 100% собственники (39 объектов).
  4. *ЦИАН (Собственники)* — интервал 2 мин, 0% комиссии.
- **Схема алгоритма «Реальный хозяин»:** Прозрачный статус проверки по частоте номеров, стоп-словам и маркерам собственника (162 одобрено / 342 отсеяно).
- **Управление PWA-кэшем:** Статус Service Worker кэша (18.4 МБ, 162 квартиры) и кнопка принудительного сброса.
