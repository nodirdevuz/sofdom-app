# Спецификация API SofDom

Сервер работает на базе FastAPI. По умолчанию запускается на порту `8000`.

## Базовый URL
```
http://localhost:8000
```

---

## Эндпоинты

### 1. Получить список квартир
`GET /api/apartments`

**Параметры запроса (Query Params):**
- `rooms` (опционально, string): фильтр по комнатам (`1,2`, `studio,1`, `all`).
- `district` (опционально, string): район Томска (`Советский`, `Кировский`, `Ленинский`, `Октябрьский`).
- `min_price` (опционально, int): минимальная цена в рублях.
- `max_price` (опционально, int): максимальная цена в рублях.
- `only_direct` (опционально, bool): только от собственников (`true`).
- `limit` (опционально, int): лимит результатов (по умолчанию 50).
- `offset` (опционально, int): смещение для пагинации.

### 2. Получить гео-метки для интерактивной карты
`GET /api/geo/map`

Возвращает облегченные координаты и цены для мгновенной отрисовки маркеров на Яндекс.Картах без перегрузки DOM.

**Ответ (200 OK):**
```json
{
  "count": 162,
  "pins": [
    {
      "id": "bezposr_196162",
      "lat": 56.4789,
      "lng": 84.9923,
      "price": 28000,
      "rooms": 1,
      "district": "Советский",
      "title": "1-комн., 38 м²",
      "photo": "https://tsk.s.bsps.ru/images/sobipro/galleries/ec/196162/3dbeb0.jpg"
    }
  ]
}
```

---

### 3. Получить детальную информацию по квартире
`GET /api/apartment/{id}`

Возвращает полный профиль квартиры, включая описание, все фото в оригинальном качестве и верификацию собственника.

---

### 4. Статистика и мониторинг
`GET /api/stats`

Возвращает распределение по источникам, средние цены по районам Томска и статус работы сборщиков.
