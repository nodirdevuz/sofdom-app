- `user: UserDTO` (`userType`, `isAgent`, `userId`, `cianUserId`).
- `bargainTerms` (`priceRur`, `deposit`, `clientFee`, `agentFee`, `utilitiesTerms`).
- `geo` (`userInput`, `coordinates: {lat, lng}`).
- `photos: List<PhotoDTO>` (`fullUrl`).
- `phones: List<Phone>` (`countryCode`, `number`).

### 1.4. Архитектура защиты (WAF / Антибот) в мобильном приложении
В `classes14.dex` декомпилированы сетевые интерцепторы:
1. `ru.cian.antibot.impl.data.interceptor.AntiBotInterceptor`:
   - Анализирует заголовки `waf-verdict` (`block`, `challenge`), `waf-verdict-reason` (`vpn`).
   - При обнаружении бот-трафика проверяет `x-yandex-captcha: 403` и бросает `AntibotException`.
   - Защита базируется на **Yandex SmartCaptcha + Yandex Cloud WAF**.
2. `ru.cian.antibot.impl.data.interceptor.CaptchaInterceptor`:
   - Ловит редирект на URL челленджа капчи, открывает WebView, получает `newSid` (Session ID).
3. `ru.cian.base.network.interceptor.UserAgentHeaderInterceptor`:
   - Добавляет обязательные мобильные заголовки:
     ```http
     Os: android
     BuildNumber: 24490300
     VersionCode: 24490300
     Device: Phone
     ApplicationID: <UUID>
     CrossApplicationID: <UUID>
     Package: ru.cian.main
     ```
4. `ru.cian.user.session.impl.data.interceptor.UserAuthInterceptor`:
   - Передаёт токен сессии в формате: `Authorization: simple <session_id>`.

### 1.5. Практический обход и прямое извлечение данных (PoC)
Мобильный API при прямом обращении с серверных IP блокируется Yandex WAF (403 VPN Block).  
**Однако веб-выдача ЦИАН с TLS-маскировкой под браузер отдаёт чистый JSON без блокировок:**

- Библиотека: `curl_cffi` с отпечатком `chrome120` (JA3/TLS fingerprinting).
- Результат: **HTTP 200 OK**.
- В HTML страницы встроен блок `window._cianConfig['frontend-serp']`, где в ключе `initialState.results.offers` содержится **полный массив из 28 объявлений на страницу с незамаскированными номерами телефонов, ценами, залогами, фото и координатами!**

## 3. БОЛЬ РЫНКА: «100% КОМИССИЯ РИЕЛТОРОВ»

### Суть проблемы для арендатора:
- Семья или мигрант находит квартиру за **40 000 ₽/мес**.
- При заселении с них требуют:
  1. Первый месяц: **40 000 ₽**
  2. Залог (депозит): **40 000 ₽**
  3. Комиссия риелтору (100%): **40 000 ₽**
- **Итого разово на руки: 120 000 ₽!**
- Риелтор в этой цепочке **не несёт никакой ответственности**, не гарантирует сохранность денег и тратит ровно 15 минут времени на показ квартиры, забирая месячную зарплату рабочего.

### Наше ценностное предложение (Value Proposition):
- Мы убираем риелтора из сделки.
- Арендатор платит за первый месяц (40 000 ₽) + залог (40 000 ₽) = **80 000 ₽**.
- **Чистая экономия арендатора: 40 000 ₽!**
- Заплатить нам **990 ₽** за прямой доступ к базе собственников — психологически невероятно лёгкое решение, экономящее клиенту 40 000 ₽.

## 4. ДВИЖОК АНТИ-РИЕЛТОР (КАК ГАРАНТИРОВАННО ОТСЕКАТЬ АГЕНТОВ)

Штатного флага «от собственника» на ЦИАН/Авито недостаточно: до 35% риелторов маскируются под собственников, покупая чистые аккаунты.

Наш алгоритм проверки состоит из 5 рубежей:
```
[Парсер: ЦИАН / Авито / Домклик / Яндекс]
                   │
                   ▼
  1. Проверка метаданных платформы
     (isByHomeowner == true, clientFee == 0, userType != "agency")
                   │
                   ▼
  2. Граф телефонов (Phone History Graph)
     (Сколько объектов висело на этом номере за 180 дней? > 2 объектов = БАН)
                   │
                   ▼
  3. Проверка тегов номера (GetContact / Numbuster API)
     (Наличие тегов "Риелтор", "Агентство", "Этажи", "Самолет Плюс" = БАН)
                   │
                   ▼
  4. NLP-анализ текста описания
     (Стоп-фразы: "комиссия по факту", "база агентства", "звонить до 21:00 агентам не беспокоить" = проверка)
                   │
                   ▼
  5. Перцептивный хэш фото (pHash Duplicate Detection)
     (Попытка выставить одну и ту же квартиру под разными номерами = БАН)
                   │
                   ▼
    [ ВЫДАЧА ЧИСТОГО СОБСТВЕННИКА В КАТАЛОГ И TELEGRAM ]
```
