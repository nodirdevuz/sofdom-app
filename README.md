# SofDom (СофДом) — Агрегатор аренды жилья от собственников в Томске

**SofDom** — специализированный высокопроизводительный сервис мониторинга, мгновенного перехвата и аналитики объявлений об аренде квартир исключительно от прямых собственников в городе Томске.

Сервис объединяет 4 независимых потока поступления данных:
1. **Авито (Ранний доступ):** перехват объявлений физических лиц через WebSocket/API pre-index за срок до 6 часов до их появления в общем каталоге.
2. **Авито (Полный каталог Томска):** непрерывный фоновый мониторинг всех свежих объявлений города с фильтрацией через анти-риелтор скоринг.
3. **БезПосредников.ру (`bsps.ru`):** специализированный сборщик 100% подтверждённых собственников.
4. **ЦИАН (Собственники):** поток предложений с нулевой комиссией и подтверждением владельца.

## 🌐 Рабочие адреса сервиса

- **Клиентское веб-приложение (витрина):** [https://nodirdevuz.github.io/sofdom-app/](https://nodirdevuz.github.io/sofdom-app/)
- **Автономная панель администратора:** `http://localhost:5173/` (дизайн-система Komfort Go)
- **Бэкенд REST API:** `http://localhost:8000/api/` (FastAPI + SQLite WAL)

## ⚡ Быстрый старт и команды управления

### 1. Клиентская витрина (`frontend`)
```bash
cd frontend
npm install
npm run dev        # Локальный запуск витрины на http://localhost:5174
npm run build      # Сборка singlefile бандла
cp dist/index.html ../index.html  # Обновление публичного файла для GitHub Pages
```

### 2. Панель администратора (`admin`)
```bash
cd admin
npm install
npm run dev        # Запуск панели управления на http://localhost:5173
npm run build      # Проверка типов (tsc -b) и production-сборка
```

### 3. Серверная часть и сборщики (`backend`)
```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
./start_live.sh    # Запуск API и фоновых харвестеров
./stop_live.sh     # Остановка всех фоновых процессов (регламент M5)
```

## 🛡 Ключевые возможности продукта

1. **100% прямые собственники без риелторов:**
   - Алгоритм многофакторного скоринга «Реальный хозяин»: проверка частоты номеров, отсев стоп-слов комиссий и агентств, подтверждение формулировок прямого владельца.
2. **Эталонная мобильная плитка по стандарту Авито:**
   - Квадратные фотографии 1:1 (`aspect-ratio: 1 / 1`), просторные вертикальные ракурсы без сплющивания комнат.
   - Скругления верхних углов 11–12px, чисто белый фон карточки `#ffffff` с микробордером `#e8eaed` на тёплом фоне ленты `#f7f8f9`.
   - Sticky Action Dock на детальной странице (48px фиксированная панель со звонком `#04e061` и сообщением) с автоматическим скрытием нижней навигации.
   - Полноэкранный Lightbox с аппаратным зумом 2x, свайпами и экранированием чужих водяных знаков.
3. **Жизненный цикл объявления: Сдано / Снято с публикации:**
   - Мгновенное исключение сданных квартир из каталога и выдачи поиска.
   - Показ контрастного баннера `✓ СДАНО • Квартира уже сдана и снята с публикации` при визите по прямой ссылке с блокировкой звонка.
   - 1-клик переключение статуса владельцем («Снять с публикации (сдано)» / «↩ Вернуть в поиск») на детальной странице и в панели администратора.
4. **Собственные фирменные идентификаторы (SD-1001 .. SD-1170):**
   - Полная независимость от внешних классифайдов. Никаких сторонних логотипов, префиксов и водяных знаков в интерфейсе.
5. **Нормализованные районы Томска:**
   - Кировский, Советский, Ленинский, Октябрьский районы + Пригород/Северск с точной привязкой координат на интерактивной карте.
6. **Встроенный «Шотчик» телеметрии и Детектор спотыканий:**
   - Непрерывный мониторинг пользовательской воронки без замедления интерфейса (fire-and-forget через `localStorage: sofdom_telemetry_events_v1`).
   - Автоматическая фиксация сбоев: битые фото на CDN (404), нулевые выдачи фильтров, задержки карт, геолокация.
7. **Автономная панель управления (дизайн Komfort Go):**
   - Строгая чёрно-серая монохромная палитра (`#111418`, `#1F2937`, `#5B6B7A`, `#ECECEC`).
   - Вкладки статуса лотов (Все, Активные, Снято) и моментальное снятие/возврат в поиск.
   - Управление пользователями (блокировка на 24 часа, вечный бан, удаление, регулировка лимитов открытий).
   - Монитор 4 сборщиков данных и PWA-кэша.
8. **Мультиагентная оркестрация:**
   - Четкое распределение обязанностей между агентом-оркестратором (`SofDom`) и агентом-партнёром (`Снайпер`) по регламенту `ORCHESTRATOR_DISPATCH.md`.
