# SofDom (СофДом) — Агрегатор аренды жилья от собственников в Томске

**SofDom** — специализированный сервис мониторинга и мгновенного перехвата объявлений об аренде квартир от прямых собственников в Томске. Сервис объединяет предложения из 3 ключевых источников: **Авито (включая секретный поток раннего доступа 6 часов)**, **ЦИАН** и **БезПосредников.ру**.

Живой продакшн-веб: [https://nodirdevuz.github.io/sofdom-app/](https://nodirdevuz.github.io/sofdom-app/)

---

## 🏗 Архитектура репозитория

```
SofDom/
├── backend/                  # Серверная часть, сборщики и база данных
│   ├── realty.db             # База SQLite в режиме WAL (Томск, 162 квартиры)
│   ├── db.py                 # Схема данных, миграции, модели и запросы
│   ├── main.py               # FastAPI бэкенд (REST API + Geo Map эндпоинты)
│   ├── scraper.py            # Мульти-парсер (ЦИАН, БезПосредников, Авито)
│   ├── ahead_of_time_harvester.py # Монитор 6-часового раннего доступа Авито
│   ├── avito_secret_scraper.py   # Извлечение секретных лотов Авито
│   ├── cross_matcher.py      # Кросс-платформенная дедупликация
│   ├── captcha_solver.py     # Обработка капчи
│   ├── start_live.sh         # Скрипт безопасного запуска сервисов
│   └── stop_live.sh          # Скрипт остановки процессов (правило батареи M5)
│
├── frontend/                 # Клиентская часть (React 18 + Vite + TypeScript)
│   ├── src/
│   │   ├── components/       # UI компоненты (ListingCard, DetailPage, Lightbox, YandexMap)
│   │   ├── data/             # Модели и нормализованные данные Томска
│   │   ├── hooks/            # Хуки (жесты свайпа, навигация)
│   │   ├── lib/              # Геокодинг и интеграция Яндекс.Карт
│   │   └── types/            # TypeScript контракты объявлений
│   ├── package.json
│   └── vite.config.ts        # Конфигурация сборки (Single-file HTML bundle)
│
├── docs/                     # Полная документация продукта
│   ├── ARCHITECTURE.md       # Подробное описание системной архитектуры
│   ├── API.md                # Спецификация REST и Geo API
│   └── PARSERS.md            # Механика сбора данных и перехвата раннего доступа
│
├── index.html                # Продакшн-бандл для мгновенного хостинга (GitHub Pages)
├── .nojekyll                 # Отключение Jekyll для быстрой сборки без ошибок
├── sofdom-logo.svg           # Фирменный логотип SofDom
└── sofdom-icon.svg           # Иконка приложения (PWA favicon)
```

## ⚡ Быстрый старт

### 1. Запуск бэкенда (API)
```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install fastapi uvicorn requests pydantic
python3 main.py
```
API будет доступно по адресу: `http://localhost:8000`  
Интерактивная документация Swagger: `http://localhost:8000/docs`

### 2. Запуск фронтенда (UI)
```bash
cd frontend
npm install
npm run dev
```

### 3. Сборка продакшн-бандла для GitHub Pages
```bash
cd frontend
npm run build
cp dist/index.html ../index.html
```

## 🛡 Ключевые возможности

1. **100% открытые телефоны:** Номера прямых собственников отображаются сразу в карточках ленты и детальном просмотре.
2. **Единый стандарт фотографий:** Пропорции 4:3, аппаратное сглаживание Retina, поддержка мобильных свайпов и полноэкранный Lightbox.
3. **Районы Томска:** Полная нормализация по 4 административным районам (Советский, Кировский, Ленинский, Октябрьский) + Пригород/Северск.
4. **Ранний доступ Авито (6 часов):** Мониторинг пре-индексных объявлений собственников до выхода в общую ленту.
